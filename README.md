clone repository ini atau download seluruhnya

### BUKA FILE MODEL IPYNB
jalankan satu persatu cell yang ada untuk load, split dataset, melatih dataset menjadi model sampai melihat hasil evaluasi

### jalankan file app.py
jalankan python app.py di terminal lalu anda akan diarahkan ke website lokal yang berisikan tampilan ui untuk web klasifikasi tumor otak

### unggah file tumor dari mana saja untuk menghasilkan klasifikasi
kelas yang tumor otak yang diklasifikasi adalah :
1. Glioma
2. Meningioma
3. No Tumor
4. Pituitary

setelah diunggah maka akan terlihat hasil akurasi dan klasifikasi masing masing kelas
